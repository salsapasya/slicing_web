## Fitur Utama
- **Desain Responsif**: Tampilan menyesuaikan dengan rapi di perangkat Mobile, Tablet, dan Desktop.
- **Smooth Scroll Navigation**: Navigasi antar-section (*Hero*, *About*, *Certificates*, *Projects*, *Contact*) berjalan secara halus.
- **Form Kontak**: Formulir interaktif untuk mengirim pesan.
